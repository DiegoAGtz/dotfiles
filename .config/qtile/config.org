* Qtile Configuration

Personal Qtile window manager configuration for a dual-screen Wayland setup.
To apply changes, tangle this file with ~C-c C-v t~, then reload Qtile with ~Mod+Ctrl+R~.

* Layouts

The primary layout is ~Columns~ (tiling with multiple column support). ~Max~ is kept
as a quick full-screen tile mode. The border colors use the Catppuccin palette:
focused windows get ~sky~, unfocused get ~surface0~.

#+begin_src python
def init_layout_theme():
    return {
        "margin": 1,
        "border_width": 2,
        "border_focus": catppuccin['sky'],
        "border_normal": catppuccin['surface0'],
    }


layout_theme = init_layout_theme()

layouts = [
    layout.Columns(**layout_theme),
    layout.Max(**layout_theme),

* Autostart

The ~run~ helper ensures each program is only launched if it isn't already running,
making the script safe to call multiple times. ~swaybg~ sets the wallpaper;
~kanshi~ handles multi-monitor display layout on Wayland.

#+begin_src bash :tangle autostart.sh :tangle-mode (identity #o755)
#!/bin/bash
function run {
  if ! pgrep -x $(basename $1 | head -c 15) 1>/dev/null;
  then
    $@&
  fi
}

run kanshi &
run nm-applet &
run blueman-applet &
run udiskie -t --appindicator &
run pasystray &
run /bin/lxqt-policykit-agent &
run emacs --daemon &
run flameshot &
swaybg -i ~/Pictures/wallpapers/0277.jpg -m fill &
#+end_src

* Startup Hook

Calls ~autostart.sh~ once at login via Qtile's ~startup_once~ hook.

#+begin_src python
@hook.subscribe.startup_once
def start_once():
    home = os.path.expanduser("~")
    subprocess.call([home + "/.config/qtile/autostart.sh"])
